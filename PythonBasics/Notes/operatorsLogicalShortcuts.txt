                  PYTHON OPERATORS FOR LOGICAL SHORTCUTS

1. MODULO OPERATOR (%) - The "Wrap-Around & Cycle" Operator
----------------------------------------------------------------------
What it does: Returns the remainder of a division.

When to use it:
* Circular Cycles: Anytime a sequence must start over after the end.
* Alternating/Grouping: Doing something every N-th time.
* Fixed Limits: Forcing numbers to stay within a specific range.

Common Coding Scenarios:
* Game turns: Player 1 -> 2 -> 3 -> back to 1.
  next_player = (current_player + 1) % total_players
* Grid layouts: Wrapping items into rows/columns.
* Time conversions: Finding leftover seconds after calculating minutes.
  remaining_seconds = total_seconds % 60
* Even/Odd checks:
  is_even = (number % 2 == 0)

Example:
# Creating a circular cycle for days of the week (0 = Sunday, 6 = Saturday)
current_day = 5  # Friday
days_to_add = 4
new_day = (current_day + days_to_add) % 7  # Result: 2 (Tuesday)


2. FLOOR DIVISION OPERATOR (//) - The "Chop the Fraction" Operator
----------------------------------------------------------------------
What it does: Divides two numbers and rounds down to the nearest whole integer.

When to use it:
* Page/Group Calculations: Working out how many full groups can be made.
* Removing Units: Dropping remainders cleanly without using functions like math.floor().

Common Coding Scenarios:
* Pagination: Calculating how many total pages are needed for items.
* Time conversions: Finding total whole hours/minutes from seconds.
  hours = total_seconds // 3600
* Splitting assets: Dividing money or items equally among a group.

Example:
# Splitting 53 candies among 5 children evenly
candies_per_child = 53 // 5  # Result: 10 (3 leftover candies are ignored)


3. MEMBERSHIP OPERATORS (in / not in) - The "Search" Operators
----------------------------------------------------------------------
What it does: Checks if a value exists inside a sequence (string, list, tuple, dict).

When to use it:
* Instead of running manual 'for' loops to search for an item.
* Validating user input against a list of allowed options.

Common Coding Scenarios:
* Punctuation filtering: Checking if a character is a symbol or space.
  if char not in alphabet: keep_as_is
* Permission checks: Checking if a user role is allowed.
  if user in admin_list: grant_access

Example:
# Replacing manual loop searches
banned_words = ["spam", "scam"]
user_message = "This is a scam alert!"

for word in banned_words:
    if word in user_message:
        print("Blocked!")


4. CONDITIONAL EXPRESSION (Ternary Operator) - The "One-Line If/Else"
----------------------------------------------------------------------
What it does: Assigns a value based on a condition in a single line.
Syntax: value_if_true if condition else value_if_false

When to use it:
* Assigning a variable status quickly without building 4 lines of if/else blocks.

Common Coding Scenarios:
* Setting default fallback values.
* Toggling a state back and forth (e.g., active/inactive).

Example:
# Traditional manual way:
if score >= 50:
    status = "Pass"
else:
    status = "Fail"

# The Operator way:
status = "Pass" if score >= 50 else "Fail"


5. EXPONENTIATION OPERATOR (**) - The "Power" Operator
----------------------------------------------------------------------
What it does: Raises a number to the power of another.

When to use it:
* Financial modeling (compound interest).
* Geometric calculations (areas, volumes).

Common Coding Scenarios:
* Calculating square roots without importing the math module (number ** 0.5).
* Growth algorithms (e.g., doubling size every level).

Example:
# Calculate compound interest: Principal * (1 + rate) ** time
investment = 1000 * (1 + 0.05) ** 3  # Growth over 3 years
