======================================================================
PYTHON max() FUNCTION - QUICK REFERENCE
======================================================================

1. BASIC USAGE (Finds the largest item)
--------------------------------------
# Pass multiple arguments:
result = max(5, 10, 3, 8)          # Output: 10

# Pass an iterable (list, tuple, etc.):
numbers = [14, 62, 9, 33]
result = max(numbers)              # Output: 62


2. USING STRINGS (Finds highest alphabetical order / ASCII)
-----------------------------------------------------------
names = ["Alice", "Bob", "Charlie"]
result = max(names)                # Output: "Charlie"


3. THE 'key' PARAMETER (Custom sorting logic)
----------------------------------------------
# Find the longest string using len():
words = ["apple", "banana", "kiwi"]
result = max(words, key=len)       # Output: "banana"

# Find the oldest person in a list of dictionaries:
people = [{"name": "A", "age": 25}, {"name": "B", "age": 40}]
result = max(people, key=lambda x: x["age"]) 
# Output: {"name": "B", "age": 40}


4. THE 'default' PARAMETER (Prevents errors on empty lists)
------------------------------------------------------------
empty_list = []
result = max(empty_list, default=0) # Output: 0 (Instead of ValueError)
